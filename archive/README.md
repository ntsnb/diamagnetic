# Archive

本目录保存不属于当前活动代码路径、活动论文主稿或原始实验资产的归档材料。

## 子目录

| 路径 | 内容 |
| --- | --- |
| `references/papers/` | 参考论文 PDF。 |
| `references/extracted_text/` | 从参考论文提取出来的阅读文本。 |
| `latex_templates/ieee_howto/` | IEEE how-to 模板和模板专用图片。 |
| `external/` | 外部项目或工具的大型压缩归档。 |
| `external_sources/` | 外部项目源树副本。 |

## 规则

- 这里的文件可用于阅读、审计和背景理解。
- 不要把这里的参考资料当成论文已经正式引用的证据。
- 如果论文需要引用某篇参考资料，必须在 LaTeX 或 BibTeX 中加入真实引用，并同步更新审计矩阵。
