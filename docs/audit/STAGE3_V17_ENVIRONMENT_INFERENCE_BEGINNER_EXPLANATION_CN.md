# Stage III V17 环境推断机制零基础说明

日期：2026-06-16

本文档目的：用中文详细解释 `V17` 中的 `environment inference`，也就是“环境推断”，到底在代码中如何计算、它和 `invariant learning`（不变学习）是什么关系、它是否仍然是旧设计中类似 `GAN`（生成对抗网络）的对抗结构，以及 `V17` 相比 `V16` 做了哪些改变。

本文档边界：本文档不是论文结论，也不声称 `V17` 已经验证成功。根据现有审计记录，`V17` 让环境推断结构更合理，并在一些目标上出现了更强的信号，但是所有正式运行仍然没有通过严格的 `teacher gate`（教师门控），因此不能把 `V17` 写成已经解决 `Stage III` 的最终方法。

---

## 1. 先给结论

如果只看一句话，`V17` 的环境推断可以这样理解：

> `V17` 不再把环境看成“每个时间点独立猜一次的类别”，而是把环境看成一个随时间演化的隐藏状态。模型先根据过去推断当前环境的先验，再根据当前输入证据修正成后验，最后用“后验减先验”的差值来表示当前是否发生了环境变化。

这句话里面有三个关键词。

第一个关键词是 `prior`（先验）。它表示模型在看当前时刻证据之前，基于过去历史认为当前环境大概是什么。

第二个关键词是 `posterior`（后验）。它表示模型看完当前时刻证据之后，对当前环境重新做出的判断。

第三个关键词是 `env_shift`（环境转移量）。它等于后验减去先验：

\[
\mathrm{env\_shift}_{t}
=
\mathrm{env\_posterior}_{t}
-
\mathrm{env\_prior}_{t}
\]

如果这个差值很小，说明当前证据和模型之前的预期差不多；如果这个差值很大，说明当前证据让模型明显改变了对环境的判断。

---

## 2. 什么是环境推断

在负荷预测中，模型看到的是历史负荷、天气、时间特征或其他外生变量。但是实际影响负荷的状态往往不是完全显式的。例如：

- 某一段时间可能处在夏季空调负荷主导状态；
- 某一段时间可能处在节假日或工作日状态；
- 某一段时间可能有天气突变；
- 某一段时间可能存在设备运行状态、用户行为或其他没有观测到的因素变化。

这些状态可以统称为 `environment`（环境）或 `regime`（运行状态、机制状态）。这里的“环境”不是自然语言里的空气环境，而是机器学习中的“数据生成机制状态”。它表示：在这一段时间里，输入和输出之间的关系处于哪一种隐含模式。

`environment inference`（环境推断）就是让模型根据当前可观测数据，估计这个隐藏环境状态。

在 `V17` 代码里，环境不是一个确定的单一标签，而是一个概率分布。配置文件中 `env_count: 4` 表示模型内部假设有四种可能的隐藏环境。每个时间点、每个专家分支都会输出一个长度为四的概率向量，例如：

\[
[0.10, 0.70, 0.15, 0.05]
\]

这表示模型认为当前状态最像第 2 个隐藏环境，但仍然保留对其他环境的概率判断。

---

## 3. V17 中环境推断的输入是什么

`V17` 不是直接对原始输入 `x` 做环境推断，而是在每个 `expert`（专家子模型）内部完成。

整体流程可以写成：

\[
x
\rightarrow
\text{temporal encoder}
\rightarrow
z
\rightarrow
\text{expert}_k
\rightarrow
h_{k,t}
\rightarrow
s_{k,t}
\rightarrow
\text{environment inference}
\]

其中：

- \(x\) 表示输入时间序列。
- \(z\) 表示全局潜变量或全局编码。
- \(\text{expert}_k\) 表示第 \(k\) 个专家分支。
- \(h_{k,t}\) 表示第 \(k\) 个专家在第 \(t\) 个时间步得到的专家状态。
- \(s_{k,t}\) 表示经过 `shared_post`（共享后处理网络）之后的专家内部表示。

在代码中，`shared_post` 是一个小型神经网络，它把专家输出转换成后续环境推断和不变/可变分解都会使用的内部表示：

\[
s_{k,t}
=
g_{\mathrm{shared}}(h_{k,t})
\]

这里的 \(g_{\mathrm{shared}}\) 对应代码里的 `self.shared_post(expert_state)`。

## 4. V17 环境推断的核心公式

`V17` 的环境推断由 `CausalEnvironmentFilter`（因果环境滤波器）完成。它的核心不是一次性分类，而是一个时间递推过程。

为了便于理解，我们先定义符号。

- \(m_{k,t}\) 表示第 \(k\) 个专家在第 \(t\) 个时间步的环境记忆状态。
- \(s_{k,t}\) 表示当前专家状态经过共享后处理后的表示。
- \(a_{k,t}\) 表示环境先验的未归一化分数。
- \(p^{-}_{k,t}\) 表示环境先验概率。
- \(b_{k,t}\) 表示当前证据对环境判断的补充分数。
- \(c_{k,t}\) 表示环境后验的未归一化分数。
- \(p^{+}_{k,t}\) 表示环境后验概率。
- \(\Delta p_{k,t}\) 表示环境转移量，也就是后验减先验。

### 4.1 第一步：根据过去记忆生成环境先验

代码逻辑是：

```python
prior_logits = self.prior_proj(hidden)
prior_post = torch.softmax(prior_logits, dim=-1)
```

数学上可以写成：

\[
a_{k,t}
=
W_{\mathrm{prior}} m_{k,t-1}
+
b_{\mathrm{prior}}
\]

\[
p^{-}_{k,t}
=
\mathrm{softmax}(a_{k,t})
\]

这一步的含义是：模型先不看当前时刻的新证据，只根据过去累计下来的环境记忆 \(m_{k,t-1}\)，猜当前时刻应该处在哪个环境。

这就是 `prior`（先验）的含义。

### 4.2 第二步：从当前专家状态提取当前证据

代码逻辑是：

```python
evidence_logits = self.evidence_proj(shared_t)
```

数学上可以写成：

\[
b_{k,t}
=
W_{\mathrm{evidence}} s_{k,t}
+
b_{\mathrm{evidence}}
\]

这一步的含义是：当前时间步的专家状态 \(s_{k,t}\) 也会提供证据。例如当前负荷形态、当前天气状态或当前局部模式，可能告诉模型“现在不像刚才那个环境了”。

### 4.3 第三步：先验加证据，得到环境后验

代码逻辑是：

```python
post_logits = prior_logits + evidence_logits
post = torch.softmax(post_logits, dim=-1)
```

数学上可以写成：

\[
c_{k,t}
=
a_{k,t}
+
b_{k,t}
\]

\[
p^{+}_{k,t}
=
\mathrm{softmax}(c_{k,t})
\]

这一步是 `V17` 环境推断中最关键的地方。

它不是完全相信过去，也不是完全相信当前，而是把“过去的预期”和“当前的证据”加在一起，再得到新的环境判断。

这和人做判断很像。例如你昨天已经知道今天可能是普通工作日，这是先验；但是你今天早上看到负荷突然升高，天气突然变热，这是当前证据；最终你会把两者结合起来，判断今天可能进入了空调负荷主导状态。

### 4.4 第四步：后验减先验，得到环境变化量

代码逻辑是：

```python
shift_parts.append(post - prior_post)
```

数学上可以写成：

\[
\Delta p_{k,t}
=
p^{+}_{k,t}
-
p^{-}_{k,t}
\]

这里的 \(\Delta p_{k,t}\) 就是代码中的 `env_shift`（环境转移量）。

这一步非常重要，因为 `Stage III` 关心的不是“当前环境是什么”这么简单，而是“当前环境是否相对于过去发生了变化”。在线学习真正需要响应的通常不是环境水平本身，而是环境变化。

### 4.5 第五步：用当前后验更新环境记忆

代码逻辑是：

```python
update_input = torch.cat([shared_t, post], dim=-1)
hidden = self.update(update_input, hidden)
```

数学上可以写成：

\[
m_{k,t}
=
\mathrm{GRUCell}
(
[s_{k,t}, p^{+}_{k,t}],
m_{k,t-1}
)
\]

这里的 `GRUCell`（门控循环单元）是一个用于时间序列记忆更新的神经网络模块。它会把当前专家状态和当前环境后验一起写入环境记忆中，供下一个时间步使用。

因此，`V17` 的环境推断是因果的。它在第 \(t\) 个时间步只使用过去记忆和当前输入，不使用未来时间步 \(t+1\) 或更晚的信息。

## 5. 为什么 V17 叫“因果环境滤波”

这里的 `causal`（因果）不是说模型已经发现了真实物理因果关系，而是说计算顺序符合时间因果性。

在第 \(t\) 个时间步，模型只能使用：

- 第 \(t\) 个时间步以前累积的隐藏状态；
- 第 \(t\) 个时间步当前可见的专家表示；
- 第 \(t\) 个时间步得到的后验，用来更新以后要用的记忆。

模型不能使用：

- 第 \(t+1\) 个时间步的输入；
- 未来真实标签；
- 未来 residual（残差）；
- 未来验证结果。

所以 `V17` 的环境推断比旧路径更接近在线场景。它至少在结构上避免了“用未来信息判断当前环境”的明显泄漏。

## 6. 环境推断如何影响不变表示 phi_i

环境推断不是单独输出一个结果就结束了。它会参与构造 `phi_i`（不变表示）和 `delta_phi_v`（可变漂移表示）。

在 `V17` 里，每个专家内部先生成一个稳定锚点：

\[
u_{k,t}
=
W_{\mathrm{anchor}} s_{k,t}
+
b_{\mathrm{anchor}}
\]

这里的 \(u_{k,t}\) 对应 `invariant_anchor`（不变锚点）。

然后模型用环境后验 \(p^{+}_{k,t}\) 对一组可学习的环境基向量做加权求和：

\[
e^{i}_{k,t}
=
\sum_{j=1}^{E}
p^{+}_{k,t,j}
B^{i}_{j}
\]

其中：

- \(E\) 是环境数量，在默认配置中是 4。
- \(B^{i}_{j}\) 是第 \(j\) 个环境对应的不变修正基向量。
- \(e^{i}_{k,t}\) 是当前环境解释出来的“不变分支中应当被扣除或修正的环境成分”。

接着模型生成一个门控向量：

\[
g^{i}_{k,t}
=
\sigma(W_{g_i}s_{k,t}+b_{g_i})
\]

这里的 \(\sigma\) 是 `sigmoid`（S 形函数），输出范围在 0 到 1 之间。它决定每个维度上要扣除多少环境成分。

最终不变表示写成：

\[
\phi^{i}_{k,t}
=
u_{k,t}
-
g^{i}_{k,t}
\odot
e^{i}_{k,t}
\]

其中 \(\odot\) 表示逐元素相乘。

这句话用中文解释就是：

> 模型先得到一个稳定锚点，然后根据环境后验估计当前哪些成分可能是环境带来的偏移，再用门控控制扣除强度，最后得到一个被环境修正过的不变表示。

这里需要非常小心。这个 `phi_i` 不能被理解为严格数学意义上完全不含环境信息的真不变表示。更准确地说，它是一个“经过环境条件修正的稳定表示”。它比直接把所有东西混在一起更有结构，但不能在论文里写成模型已经严格学到了真实不变因子。

## 7. 环境推断如何影响可变漂移 delta_phi_v

`V17` 的可变分支由三部分组成。

第一部分是基础漂移分支：

\[
d^{\mathrm{base}}_{k,t}
=
W_{\mathrm{drift}}s_{k,t}
+
b_{\mathrm{drift}}
\]

第二部分是环境水平调制项：

\[
d^{\mathrm{env}}_{k,t}
=
g^{d}_{k,t}
\odot
\sum_{j=1}^{E}
p^{+}_{k,t,j}
B^{d}_{j}
\]

它使用的是环境后验 \(p^{+}_{k,t}\)，所以它表达“当前处在哪个环境水平下，漂移分支应该如何变化”。

第三部分是环境转移调制项：

\[
d^{\mathrm{trans}}_{k,t}
=
g^{T}_{k,t}
\odot
\sum_{j=1}^{E}
\Delta p_{k,t,j}
B^{T}_{j}
\]

它使用的是环境转移量 \(\Delta p_{k,t}\)，所以它表达“当前环境判断相对于先验发生了什么变化”。

最终可变漂移表示是：

\[
\Delta \phi^{v}_{k,t}
=
d^{\mathrm{base}}_{k,t}
+
d^{\mathrm{env}}_{k,t}
+
d^{\mathrm{trans}}_{k,t}
\]

这就是 `V17` 相比 `V16` 很重要的改变。`V16` 主要使用环境后验本身，而 `V17` 额外引入了“后验减先验”的环境变化项。这样一来，可变分支不仅知道当前环境是什么，还知道当前环境是否相对于历史预期发生了改变。

---

## 8. 为什么还要做正交投影

代码中还有一步：

```python
delta_phi_v = _project_delta_orthogonal_to_anchor(delta_phi_v, phi_i, eps)
```

它的作用是把 \(\Delta \phi^{v}_{k,t}\) 中和 \(\phi^{i}_{k,t}\) 平行的部分去掉。

数学上可以写成：

\[
\mathrm{parallel}
=
\frac{
\Delta \phi^{v}_{k,t}
\cdot
\phi^{i}_{k,t}
}{
\|\phi^{i}_{k,t}\|^2+\epsilon
}
\phi^{i}_{k,t}
\]

\[
\Delta \phi^{v,\perp}_{k,t}
=
\Delta \phi^{v}_{k,t}
-
\mathrm{parallel}
\]

直观解释是：

> 如果可变分支和不变分支朝着同一个方向表达信息，那么两条分支就没有真正分工。正交投影试图让可变分支少复制不变分支已经表达的内容。

但是这一步也不能被过度解释。正交只是一种几何约束，它只能减少两个向量的线性重叠，不能自动保证一个向量就是真实长期规律、另一个向量就是真实短期扰动。后续实验仍然必须证明这个分解对预测和在线适应有用。

## 9. phi_v 是如何得到的

`V17` 仍然使用：

\[
\phi^{v}_{k,t}
=
\phi^{i}_{k,t}
+
\Delta \phi^{v}_{k,t}
\]

也就是说，`phi_v`（可变表示）不是完全从零开始生成的另一个空间，而是在 `phi_i`（不变表示）的基础上加上一个可变残差。

这比直接让 `phi_i` 和 `phi_v` 分别由两个完全无关网络生成要更容易对齐，因为二者至少共享同一个专家内部坐标系统。

但这也带来一个风险。如果 \(\Delta \phi^{v}\) 没有学到真正有预测价值的变化信息，那么 `phi_v` 只是在 `phi_i` 上加了一个看起来复杂但实际没用的扰动。因此 `V17` 仍然必须通过 `teacher-only probe`（仅教师诊断）来验证漂移信号是否真的有用。

## 10. V17 如何把专家预测组合起来

每个专家都会输出三类预测：

\[
\hat{y}^{i}_{k}
=
f^{i}_{k}(\mathrm{pool}(\phi^{i}_{k,t}))
\]

\[
\hat{y}^{v}_{k}
=
f^{v}_{k}(\mathrm{pool}(\Delta\phi^{v}_{k,t}))
\]

\[
\hat{y}_{k}
=
\hat{y}^{i}_{k}
+
\hat{y}^{v}_{k}
\]

其中：

- \(\hat{y}^{i}_{k}\) 是第 \(k\) 个专家的不变分支预测。
- \(\hat{y}^{v}_{k}\) 是第 \(k\) 个专家的可变残差分支预测。
- \(\hat{y}_{k}\) 是第 \(k\) 个专家的完整预测。

最终模型不是简单平均所有专家，而是学习专家权重：

\[
\alpha
=
\mathrm{softmax}
(
\mathrm{alpha\_head}(z)
+
\mathrm{env\_router\_bias}
)
\]

其中：

\[
\mathrm{env\_router\_bias}
=
\mathrm{router\_env\_head}
(
\mathrm{pool}(\mathrm{env\_shift})
)
\]

这说明 `V17` 的专家路由也受到环境变化影响。也就是说，如果某个专家更适合当前环境转移状态，模型可以提高这个专家的权重。

最终预测为：

\[
\hat{y}
=
\sum_{k=1}^{K}
\alpha_k
\hat{y}_{k}
\]

## 11. V17 的训练目标是什么

`V17` 不是只靠预测误差训练。它还加入了多种辅助损失，用来约束环境推断、专家分工、不变分支和可变分支。

整体训练目标可以概括为：

\[
\mathcal{L}_{V17}
=
\mathcal{L}_{rep}
+
\mathcal{L}_{vae}
+
\lambda_{lb}\mathcal{L}_{load\_balance}
+
\lambda_{eb}\mathcal{L}_{env\_balance}
+
\lambda_{ed}\mathcal{L}_{expert\_diversity}
+
\lambda_{if}\mathcal{L}_{local\_inv}
+
\lambda_{res}\mathcal{L}_{local\_res}
+
\lambda_{et}\mathcal{L}_{env\_temporal}
+
\lambda_{rs}\mathcal{L}_{router\_stability}
\]

下面逐个解释。

### 11.1 表示学习损失

`\mathcal{L}_{rep}` 表示已有的对齐表示损失集合，包括预测损失、残差损失、正交损失、平滑损失、相关性约束和方差协方差约束等。

它的目的不是专门训练环境推断，而是让 `phi_i`、`delta_phi_v`、`y_inv`、`y_var` 之间保持基本合理的预测分工。

### 11.2 环境均衡损失

代码中的环境均衡损失是：

\[
\mathcal{L}_{env\_balance}
=
\mathrm{mean}
(
(\bar{p}-\frac{1}{E})^2
)
-
0.1
\cdot
H(p)
\]

其中：

- \(\bar{p}\) 是所有样本、所有专家、所有时间步上的平均环境后验；
- \(\frac{1}{E}\) 是均匀分布；
- \(H(p)\) 是环境后验的熵。

它的直觉是：

> 模型不要把所有样本都塞进同一个环境，也不要让环境后验过早塌缩成单一类别。

这可以减少环境推断变成无意义常数的风险。

### 11.3 专家多样性损失

专家多样性损失作用在不同专家的 \(\Delta\phi_v\) 上。

它希望不同专家的可变漂移表示不要完全一样。如果所有专家都学成同一个东西，那么混合专家模型就失去了意义。

### 11.4 局部不变预测损失

局部不变预测损失让每个专家自己的不变分支也能预测目标：

\[
\mathcal{L}_{local\_inv}
=
\mathbb{E}
[
\alpha_k
\cdot
\|
\hat{y}^{i}_{k}
-
y
\|^2
]
\]

这里的 \(\alpha_k\) 会被 `detach`，也就是只作为权重使用，不反向改变路由器本身。

直觉是：

> 不变分支不能只是一个漂亮的中间向量，它必须保留实际预测能力。

### 11.5 局部残差预测损失

局部残差预测损失让每个专家的可变分支预测不变分支没解释掉的部分：

\[
\mathcal{L}_{local\_res}
=
\mathbb{E}
[
\alpha_k
\cdot
\|
\hat{y}^{v}_{k}
-
(y-\hat{y}^{i}_{k})
\|^2
]
\]

这里的 \(\hat{y}^{i}_{k}\) 在目标中被 `detach`，所以可变分支是在追不变分支留下的残差。

直觉是：

> 可变分支不要和不变分支抢同一个任务，而应该去解释不变分支解释不了的误差。

### 11.6 环境时间平滑损失

环境时间平滑损失是：

\[
\mathcal{L}_{env\_temporal}
=
D_{KL}
(
p^{+}_{t}
\|
p^{-}_{t}
)
+
0.1
\cdot
\|
\Delta p_t
\|^2
\]

其中 \(D_{KL}\) 是 `KL divergence`（KL 散度），用来衡量两个概率分布之间的差异。

这个损失的作用是：

> 环境可以变化，但是不要没有理由地剧烈跳变。

它是合理的，但也有潜在风险。如果这个约束太强，模型可能会把真实的短期漂移也压平，导致 `Stage III` 拿不到足够敏感的变化信号。

### 11.7 路由稳定损失

路由稳定损失会根据每个专家预测误差构造一个目标专家权重。误差小的专家应该得到更高权重，误差大的专家应该得到更低权重。

直觉是：

> 专家路由不应该完全随意，而应该和专家预测能力保持一致。

## 12. V17 还是旧设计中类似 GAN 的结构吗

简短回答是：不是。

更准确地说：

> 旧设计中“环境推断和不变学习是一对类似生成对抗网络的结构”这个想法，在概念上还留下了影响；但是 `V17` 当前代码实现不是 `GAN` 式对抗训练，也不是严格的环境判别器对抗不变学习。

### 12.1 旧设想是什么

旧论文或旧设想中曾经有这样的表达：

\[
\mathcal{M}_{EI}
\quad
\text{和}
\quad
\mathcal{M}_{IL}
\]

其中：

- \(\mathcal{M}_{EI}\) 表示 `environment inference module`（环境推断模块）。
- \(\mathcal{M}_{IL}\) 表示 `invariant learning module`（不变学习模块）。

旧设想更接近以下逻辑：

1. 环境推断模块努力从表示中预测环境标签。
2. 不变学习模块努力让表示不包含环境信息。
3. 如果环境推断模块预测不出环境，说明不变表示可能压掉了环境相关因素。

这个想法和 `GAN` 有相似之处，因为二者都有“一个模块试图区分，另一个模块试图让它区分不了”的味道。

但是这个说法在审计中已经被标记为风险表述。原因是仓库里缺少对应的完整实现证据，例如：

- 没有明确的环境判别器作为对手；
- 没有梯度反转层；
- 没有严格的 min-max 对抗优化；
- 没有证明收敛后环境信息真的从不变表示中被去掉；
- 旧路径中环境分配还曾经依赖真实标签或 residual，这不适合直接用于在线环境推断。

### 12.2 GAN 式对抗训练通常长什么样

如果真的要做类似 `GAN` 的环境不变学习，通常会有两个目标。

环境判别器的目标是：

\[
\min_{\theta_E}
\mathcal{L}_{env}
(
D_{\theta_E}(\phi_i),
e
)
\]

这表示环境判别器 \(D_{\theta_E}\) 想从 \(\phi_i\) 中预测环境标签 \(e\)。

不变表示学习器的目标是：

\[
\min_{\theta_I}
\mathcal{L}_{forecast}
-
\lambda
\mathcal{L}_{env}
(
D_{\theta_E}(\phi_i),
e
)
\]

这里的负号表示不变表示学习器希望环境判别器预测失败。

这种结构通常需要 `gradient reversal layer`（梯度反转层）或交替训练。环境判别器变强时，不变编码器被迫隐藏环境信息。

### 12.3 V17 实际做了什么

`V17` 没有这样做。

`V17` 的环境推断模块不是一个被不变学习模块“欺骗”的对手。它是一个辅助的时间滤波器。它输出的环境后验会直接被用于：

- 修正不变表示；
- 调制可变漂移；
- 影响专家路由；
- 形成环境转移信号。

也就是说，`V17` 中的环境推断和不变学习不是敌对关系，而是协作关系。

可以把 `V17` 理解为：

\[
\text{环境推断}
\rightarrow
\text{条件修正不变表示}
\]

\[
\text{环境推断}
\rightarrow
\text{条件生成漂移表示}
\]

\[
\text{环境转移}
\rightarrow
\text{影响专家路由和 Stage III 漂移信号}
\]

所以，`V17` 仍然保留了“用环境推断帮助不变学习”的想法，但它已经不再是旧稿中那种类似 `GAN` 的对抗式表述。

更严谨的说法应该是：

> `V17` implements a causal latent-environment filter that conditions invariant correction and drift decomposition.

中文可以写成：

> `V17` 实现了一个因果隐藏环境滤波器，用这个滤波器的环境后验和环境转移量来条件化不变表示修正与漂移分解。

## 13. V17 相比 V16 改了什么

### 13.1 V16 的环境推断是逐点、无记忆的

在 `V16` 中，环境推断大致是：

\[
s_{k,t}
=
g_{\mathrm{shared}}(h_{k,t})
\]

\[
\ell_{k,t}
=
W_{\mathrm{env}}s_{k,t}
+
b_{\mathrm{env}}
\]

\[
p_{k,t}
=
\mathrm{softmax}(\ell_{k,t})
\]

它只根据当前时间步的专家表示 \(s_{k,t}\) 估计环境后验 \(p_{k,t}\)。

这个设计有一个明显问题：每个时间步之间没有显式环境记忆。模型今天怎么判断环境，不会明确参考昨天或上一个时间步的环境判断。

这就是审计记录里说的 `memoryless`（无记忆）环境推断。

### 13.2 V17 增加了先验和后验

`V17` 改成：

\[
p^{-}_{k,t}
=
\mathrm{softmax}
(
W_{\mathrm{prior}}m_{k,t-1}
+
b_{\mathrm{prior}}
)
\]

\[
p^{+}_{k,t}
=
\mathrm{softmax}
(
W_{\mathrm{prior}}m_{k,t-1}
+
W_{\mathrm{evidence}}s_{k,t}
+
b
)
\]

\[
\Delta p_{k,t}
=
p^{+}_{k,t}
-
p^{-}_{k,t}
\]

这让模型能区分两件事：

- 当前环境水平是什么；
- 当前环境相对于历史预期发生了多大改变。

### 13.3 V17 让漂移分支使用环境转移，而不只是环境水平

`V16` 的可变分支主要是：

\[
\Delta\phi^{v}_{k,t}
=
\mathrm{drift\_base}
+
\mathrm{drift\_env}(p_{k,t})
\]

`V17` 改成：

\[
\Delta\phi^{v}_{k,t}
=
\mathrm{drift\_base}
+
\mathrm{drift\_env}(p^{+}_{k,t})
+
\mathrm{transition\_env}(\Delta p_{k,t})
\]

新增的 \(\mathrm{transition\_env}(\Delta p_{k,t})\) 是 `V17` 的关键。

因为 `Stage III` 要捕捉的是变化，而不是只知道当前属于哪个环境。比如“天气一直很热”和“天气刚刚突然变热”对在线适应来说不是同一件事。

### 13.4 V17 把每个专家自己的预测分支显式监督起来

`V16` 中，最终预测监督主要发生在专家融合之后。也就是说，模型最终输出好不好，会反向影响所有分支，但每个专家内部的不变预测和可变预测没有那么明确的独立监督。

`V17` 让每个专家都有：

- `expert_y_inv`，也就是专家自己的不变分支预测；
- `expert_y_var`，也就是专家自己的可变残差分支预测；
- `expert_y_hat`，也就是二者相加后的专家完整预测。

这使得每个专家内部就承担预测任务，而不是等所有专家融合后才承担任务。

### 13.5 V17 让专家路由依赖环境变化

`V16` 的专家权重主要来自全局潜变量 \(z\)。

`V17` 额外加入：

\[
\mathrm{env\_router\_bias}
=
\mathrm{router\_env\_head}(\mathrm{pooled\_env\_shift})
\]

最终：

\[
\alpha
=
\mathrm{softmax}
(
\mathrm{alpha\_head}(z)
+
\mathrm{env\_router\_bias}
)
\]

这意味着专家选择会参考环境是否发生变化。某个专家可以在某种环境转移模式下被提高权重。

## 14. V17 的好处是什么

从设计角度看，`V17` 有几个明显好处。

第一，它比 `V16` 更符合时间顺序。环境判断不是每个时间点独立猜一次，而是通过隐藏状态连续更新。

第二，它把“当前环境水平”和“环境变化”分开了。`Stage III` 更关心环境变化，所以 `env_shift` 比单纯的 `env_posterior` 更接近在线学习需要的信号。

第三，它把专家内部的不变预测和可变残差预测显式监督起来。这样可变分支更有机会学习“不变分支解释不了的残差”。

第四，它让专家路由也感知环境变化。这样不同专家不只是根据全局潜变量分工，也可以根据环境转移状态动态改变权重。

---

## 15. V17 的风险是什么

`V17` 结构更合理，不等于它已经成功。

第一个风险是：环境状态仍然是模型自己学出来的隐藏类别，不是真实可解释标签。它可能对应季节、天气、工作日，也可能只是神经网络为了降低损失形成的内部聚类。

第二个风险是：环境时间平滑可能压制真实漂移。如果 \(\mathcal{L}_{env\_temporal}\) 太强，模型会倾向于让环境后验不要变化太大，这可能让 `env_shift` 变弱。

第三个风险是：不变表示仍然不是严格不变。`phi_i` 是环境条件修正后的表示，不是通过严格对抗训练或因果证明得到的真实不变因子。

第四个风险是：`env_shift` 有变化不代表它一定对预测有用。真正要证明的是：使用 `env_shift` 和 `delta_phi_v` 后，在控制 `history_only`（只用历史模式）之后仍然有稳定增益。

第五个风险是：现有正式实验没有通过教师门控。审计记录显示，`V17` 在某些运行中产生了更强信号，但仍然存在跨随机种子、跨数据集和反事实归因门槛不足的问题。因此不能说它已经支持安全训练生成器。

## 16. 你之前的 GAN 式理解应该如何更新

你原来的理解可以保留一部分，但需要改写。

不建议继续理解为：

> 环境推断模块和不变学习模块像生成对抗网络一样互相对抗，最后环境推断失败就说明学到了真正不变表示。

更建议更新为：

> 环境推断模块在 `V17` 中是一个因果时间滤波器。它不是不变学习模块的敌人，而是给不变分支和可变分支提供条件变量。模型根据环境后验扣除或修正不变表示中的环境成分，根据环境转移量构造可变漂移表示，再通过教师诊断检查这些漂移信号是否真的比历史基线更有预测价值。

这两种理解的区别很大。

旧理解强调“对抗”。它问的是：环境信息能不能从不变表示里被完全消掉。

`V17` 强调“条件分解”。它问的是：环境后验和环境转移能不能帮助模型把稳定部分和变化部分分开，并且让变化部分对在线预测有增量价值。

## 17. 如果写论文，应该怎么表述 V17

根据当前证据，更安全的论文表述是：

> We replace the memoryless environment router with a causal latent-environment filter. The filter first estimates an environment prior from the previous hidden state, then combines the prior with current expert evidence to obtain a posterior. The posterior-prior difference is used as an environment-shift signal for expert-local drift decomposition and routing.

对应中文含义是：

> 我们将无记忆环境路由器替换为因果隐藏环境滤波器。该滤波器先根据上一时刻隐藏状态估计环境先验，再结合当前专家证据得到环境后验。后验与先验之差被用作环境转移信号，用于专家内部漂移分解和专家路由。

不建议写成：

> `V17` proves that the model learns true invariant features through adversarial environment inference.

对应中文含义是：

> `V17` 证明模型通过对抗式环境推断学到了真实不变特征。

这句话目前没有代码和实验共同支持。

## 18. 最后用一个生活类比解释

可以把 `V17` 想象成一个根据天气和用电习惯开空调的管家。

`V16` 的管家每隔一小时看一次当前温度，然后独立判断“现在是什么状态”。它不太记得刚才判断过什么，所以容易把短时噪声当成状态变化。

`V17` 的管家会先记住过去的状态。比如它先认为“今天大概率还是普通工作日负荷状态”，这就是先验。然后它看到当前温度突然升高、负荷曲线变陡，就把判断改成“可能进入空调高负荷状态”，这就是后验。先验和后验之间的差，就是它感受到的环境变化。

然后这个环境变化会影响两件事。

第一，它会告诉稳定分支：哪些变化可能只是环境扰动，不要把它们误当成长期规律。

第二，它会告诉可变分支：这里可能有短期漂移，需要尝试解释不变分支解释不了的残差。

但是，管家感觉到天气变了，不代表它的调节一定正确。它还要通过反事实对照和滚动验证证明：真实环境变化信号确实比乱序、反号、放大或只用历史的方案更好。`V17` 当前的问题就在这里：它的结构更像一个认真工作的管家，但还没有稳定通过所有考核。
