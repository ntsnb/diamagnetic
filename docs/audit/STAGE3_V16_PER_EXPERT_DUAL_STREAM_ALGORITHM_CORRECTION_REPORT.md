# Stage III V16：每个专家分支内双流不变学习算法更正报告

日期：2026-06-16

## 一、报告目的

本报告用于审计你提出的新算法思路，并把口语化想法整理成可以被代码实现、实验验证和论文表述使用的严格版本。

你的核心想法可以重新表述为：

> 不再把两个相互独立或弱相关的表示向量直接相减，而是在每一个专家分支内部做不变表示学习。每个专家分支先共享大部分表示层，然后在后段分成双流结构。一条流学习该专家下相对稳定、长期有用的表示，作为 `phi_i`。另一条流在环境推断和不变学习约束下学习可变残差，作为 `delta`。最终令 `phi_v = phi_i + delta`。这样，`phi_i` 和 `phi_v` 来自同一个专家内的共享表示底座，坐标更容易对齐，正交、泄漏控制和零漂移恒等约束也更容易定义。

本报告不会把该想法写成已经成功的实验结论。它只回答三个问题：

1. 这个想法在数学和深度学习结构上是否比旧方案更合理。
2. 它能解决哪些旧问题，不能自动解决哪些旧问题。
3. 如果把它作为 Stage III V16 的新方向，最低风险的实验和实现边界应该是什么。

## 三、总判断

我认可你的数学直觉：直接对 `phi_v` 和 `phi_i` 做相减，确实不是一个天然可靠的操作。两个向量能不能相减，不只取决于维度是否一样，还取决于它们是否处在同一个向量空间、同一组坐标轴、同一套尺度和同一类语义解释下。

你的新思路比旧的“后处理式向量相减”更合理。因为它把不变表示和可变残差放在每个专家分支内部，从同一个共享表示底座分出双流。这样，`phi_i` 和 `delta` 的关系是模型结构直接规定出来的，而不是事后拿两个可能不在同一空间的向量强行相减。

但是，这个新思路目前只能被视为一个更合理的算法假设，不能被视为已经验证的 Stage III 机制。原因是：V13、V14 和 V15 的核心失败不是单纯“向量相减不优雅”，而是当前漂移信号没有稳定证明自己能在因果残差历史之外提供额外预测信息。

因此，当前最准确的结论是：

```text
每个专家分支内双流不变学习，是一个值得进入 V16 设计规格的新方向。
它有可能缓解 phi_i 与 phi_v 的坐标错配问题。
但它还没有证明能够产生有效的在线漂移修正信号。
在通过 teacher-only 诊断和 V15 风格残差目标门槛之前，不能训练生成器，也不能写成论文主贡献。
```

## 四、当前旧结构的问题在哪里

当前基础预测器大致是这样的：

```text
输入序列
-> 时间编码器
-> VAE 潜变量 z
-> alpha_head 得到专家权重
-> 多个 VariableAxisExpert 专家分支
-> 按专家权重融合
-> output_head
-> 预测值 y_hat
```

这个结构里的专家分支主要服务于基础预测。它们并不直接产生 Stage III 使用的 `phi_i` 和 `phi_v`。

当前 Stage III 表示路径是另一条全局表示路径，大致是：

```text
输入
-> 共享表示主干
-> invariant head 得到 phi_i
-> variant residual head 得到 delta_phi_v
-> phi_v = phi_i + delta_phi_v
```

这已经比早期两个独立编码器更安全，因为它至少让 `phi_v` 被定义为 `phi_i` 加上一个残差。但是，它仍然是全局表示，不是从每个预测专家内部的真实工作状态中产生的。

这带来一个重要问题：Stage III 的漂移信号和基础预测器真正使用的专家状态之间存在语义间隔。换句话说，基础模型做预测时使用的是专家分支输出，而 Stage III 判断漂移时使用的是另一个全局表示模型。这两者不一定完全对应。

V13 之后，Stage III 信号被改成更严格的波动定义：

```text
delta_phi_v(t) = phi_v(t) - phi_i(t)
fluctuation_delta(t) = delta_phi_v(t) - delta_phi_v(t-1)
```

这个修正是合理的，因为它不再只看当前的静态差值，而是看相邻时刻之间可变残差的变化。但实验结果仍然不支持强 claim：

- V12 对齐门槛可以通过，但 teacher gate 和 rolling validation 仍然失败。
- V13 的 `fluctuation_delta` 有局部正向迹象，但不稳定，不能解锁生成器。
- V14 使用更严格的线性读出后，信号被进一步否定。
- V15 直接检查 `fluctuation_delta` 是否能在 `history_only` 之外预测残差主目标，结果两个主目标都失败。

这说明旧问题不只是几何问题，也包括信号内容问题。

## 五、为什么直接相减在数学上不充分

直接写：

```text
drift = phi_v - phi_i
```

看起来简单，但它隐含了很多未经证明的前提。

第一个前提是同空间。`phi_i` 和 `phi_v` 必须属于同一个向量空间。如果它们来自不同编码器，或者来自不同损失函数主导的表示空间，那么它们虽然维度相同，但坐标轴含义可能不同。

第二个前提是同尺度。即使两个向量在同一空间，如果一个分支输出的数值尺度更大，另一个分支输出的数值尺度更小，相减结果也会被尺度差异主导，而不一定代表真实漂移。

第三个前提是同语义。比如 `phi_i` 的第 10 维可能代表日周期稳定特征，而 `phi_v` 的第 10 维可能代表近期负荷幅值变化。这两个数相减不会自动得到“概念漂移”。

第四个前提是重参数化不敏感。神经网络的隐空间可以旋转、缩放或重排，只要下游预测头能适应，预测结果可能不变。但 `phi_v - phi_i` 会受到这些任意坐标变化影响。也就是说，相减结果可能反映的是表示坐标的任意选择，而不是真实物理或统计变化。

所以，更安全的数学定义不是：

```text
先学 phi_i，再学 phi_v，然后直接相减。
```

更安全的定义是：

```text
先学共享稳定底座 phi_i，再显式学习相对于 phi_i 的残差 delta，最后定义 phi_v = phi_i + delta。
```

你的新思路正是朝这个方向推进。

## 六、把新思路形式化

设第 `e` 个专家在时间 `t` 的共享状态为：

```text
h_e(t)
```

在这个专家内部，先共享大部分层，然后分成两条后段分支：

```text
phi_i^e(t) = H_i^e(h_e(t))
delta_e(t) = H_delta^e(h_e(t), q_env^e(t))
phi_v^e(t) = phi_i^e(t) + delta_e(t)
```

这里：

- `phi_i^e(t)` 表示第 `e` 个专家内部的稳定表示。
- `delta_e(t)` 表示第 `e` 个专家内部相对于稳定表示的可变残差。
- `phi_v^e(t)` 表示稳定表示加上可变残差之后的专家局部可变表示。
- `q_env^e(t)` 表示第 `e` 个专家内部推断出的环境状态或环境概率。

Stage III 真正需要的短期波动，不建议继续使用静态层面的 `phi_v^e(t) - phi_i^e(t)`。因为这个差值等于 `delta_e(t)`，它仍然可能包含缓慢变化。更合理的是使用时间变化：

```text
fluctuation_e(t) = delta_e(t) - delta_e(t-1)
```

这与之前你对 `phi_v - phi_i` 的修正思路一致：Stage III 应该更关注短期波动，而不是长期平稳变化。

多个专家的信号可以有两种汇聚方式。

第一种是专家权重加权：

```text
stage3_signal(t) = sum_e alpha_e(t) * fluctuation_e(t)
```

这种方式简单，维度较低，适合第一轮 V16 诊断。

第二种是保留每个专家的展开向量：

```text
stage3_signal(t) =
[alpha_1(t) * fluctuation_1(t),
 alpha_2(t) * fluctuation_2(t),
 ...,
 alpha_K(t) * fluctuation_K(t)]
```

这种方式信息更多，但维度更高，更容易过拟合。第一轮不建议直接采用。

## 七、新设计可以改善哪些旧问题

### 1. 可以改善坐标对齐问题

因为 `phi_i^e` 和 `delta_e` 来自同一个专家内部共享状态，所以它们比两个独立编码器更容易处在一致的坐标系统中。

这不能保证语义完全正确，但至少比“两个不同来源的向量事后相减”更干净。

### 2. 可以改善训练和部署之间的语义间隔

旧的 Stage III 表示来自全局表示模型，而基础预测来自专家分支。新的设计从专家内部状态直接产生漂移候选信号，因此更接近基础预测器真正使用的内部机制。

这对在线学习尤其重要。因为在线修正应该围绕模型实际使用的状态发生，而不是围绕一个旁路表示模型发生。

### 3. 可以更自然地施加正交约束

在每个专家内部，可以把 `delta_e` 中沿着 `phi_i^e` 的方向扣掉：

```text
delta_e_perp =
delta_e - projection(delta_e on phi_i^e)
```

这可以减少稳定表示和可变残差之间的信息重复。

但是必须强调：正交只能说明几何上不重叠，不等于因果上解耦，也不等于 `delta_e` 一定是短期未观测因素。

### 4. 可以更容易保证零漂移恒等

新设计可以强制：

```text
如果 delta_e(t) = 0，那么 phi_v^e(t) = phi_i^e(t)。
```

这比旧的生成器路径更安全。旧路径曾经存在过零漂移仍然产生非零参数扰动的问题，因为生成器内部偏置和缩放结构会让零输入也产生输出。

### 5. 可以支持专家级诊断

新设计可以回答旧结构无法直接回答的问题：

- 哪个专家分支的漂移信号有用。
- 哪个专家分支只是在重复历史残差。
- 哪个专家分支发生了塌缩。
- 环境推断是否只是复制了专家门控权重。
- 正交约束是否真的提升了残差可预测性。

这些诊断对后续论文重构很重要。

## 八、新设计不能自动解决哪些问题

### 1. 不能自动证明有增量信息

这是最重要的问题。

V15 的核心结论是：当前 `fluctuation_delta` 没有稳定证明自己能在 `history_only` 之外预测主残差目标。

即使 V16 的专家内双流结构更合理，也必须重新证明：

```text
expert_delta_plus_history 优于 history_only。
```

如果做不到，那么新表示只是更漂亮的表示，不是有效的在线漂移信号。

### 2. 不能自动保证环境推断是因果可用的

当前仓库里的环境推断原型更适合离线训练，不适合直接搬到在线部署路径。因为训练时可以使用标签或损失来辅助推断环境，而在线预测时当前真实标签和未来残差都不可见。

所以 V16 必须明确规定：

```text
环境推断在时间 t 只能使用时间 t 可获得的信息。
```

允许使用的信息包括：

- 当前输入特征；
- 当前模型隐藏状态；
- 日历和时间特征；
- 已经释放的历史残差；
- 过去的专家权重统计；
- 过去的环境后验统计。

禁止使用的信息包括：

- 当前真实标签；
- 当前预测 horizon 的真实残差；
- 未来窗口标签；
- 验证集或测试集标签拟合出来的环境原型；
- 任何测试集反馈调参。

### 3. 不能自动避免专家塌缩

当前专家混合模型使用 softmax 专家权重。如果没有专家使用率约束，模型可能长期只使用少数专家。这样，即使每个专家都加了双流结构，大部分分支也没有足够数据学到可靠表示。

因此必须报告：

- 每个专家的平均权重；
- 专家权重熵；
- 有效专家数量；
- 每个专家的样本覆盖量；
- 每个专家的环境分布；
- 是否存在长期接近零使用率的专家。

### 4. 不能把正交约束当成因果证明

正交约束是几何约束，不是因果识别。

不能写：

```text
正交约束证明了不变因素和可变因素已经解耦。
```

只能写：

```text
正交约束用于降低稳定表示和可变残差之间的信息重叠。
```

如果要进一步证明它有用，必须做正交消融实验，比较有无正交约束时残差目标可预测性是否提高。

### 5. 不能直接解锁生成器训练

V16 第一阶段不应该训练生成器。

生成器训练必须在 teacher-only 诊断通过之后才允许。否则，生成器可能会学习到一个验证集偶然有效、但不具备真实漂移含义的修正路径。

## 九、建议的 V16 非覆盖设计边界

建议把这个方向命名为：

```text
Stage III V16: Expert-Local Dual-Stream Invariant Residual Diagnostic
```

中文可以写为：

```text
Stage III V16：专家局部双流不变残差诊断
```

第一版 V16 不应该替换旧代码，而应该作为新的非覆盖诊断路径。

基本边界如下：

1. 不修改 V12、V13、V14、V15 的原始实现文件。
2. 不覆盖旧日志、旧 checkpoint、旧表格、旧图像。
3. 不训练 Stage III generator。
4. 只做 expert-local teacher-only 诊断。
5. 沿用 V15 的因果历史基线和反事实信号门槛。
6. 只有 teacher-only 证据通过后，才考虑生成器 canary。

第一轮 V16 只回答一个问题：

```text
每个专家内部双流残差信号，是否能在因果残差历史之外提供稳定增量预测价值？
```

如果这个问题答案是否定的，V16 应该停止，不进入生成器训练。

## 十、建议的模块契约

V16 不应该复制一整套新专家主干。最低风险做法是在现有专家输出状态之后接一个轻量双流头。

建议模块输出如下：

```text
ExpertDualStreamOutput:
    phi_i_e: 第 e 个专家的稳定表示
    delta_e: 第 e 个专家的可变残差表示
    phi_v_e: phi_i_e + delta_e
    q_env_e: 第 e 个专家的因果环境后验或环境原型权重
    diagnostics: 范数、秩、正交度、环境熵等诊断值
```

建议前向传播契约如下：

```text
输入:
    expert_state_e(t)
    causal_context(t)

输出:
    phi_i_e(t)
    delta_e(t)
    phi_v_e(t)
```

必须满足的结构不变量：

1. `phi_i_e`、`delta_e`、`phi_v_e` 的形状必须兼容。
2. `phi_v_e = phi_i_e + delta_e` 必须由结构保证，而不是事后近似。
3. 如果 `delta_e = 0`，Stage III 漂移贡献必须为零。
4. 所有归一化器、环境原型、对齐器只能在训练集拟合。
5. 验证集和测试集只能调用冻结后的变换。
6. 在线推断不能读取当前或未来标签。

## 十一、建议的损失函数设计

V16 不能只依赖一个正交损失。更合理的训练目标应该包含以下部分。

### 1. 基础预测保持损失

该损失保证新分支不会破坏基础预测能力：

```text
L_forecast = 基础预测误差
```

如果加了双流结构之后基础预测明显恶化，那么后续漂移诊断会被污染。

### 2. 不变表示预测损失

该损失保证 `phi_i_e` 不是空表示：

```text
L_invariant = 基于 phi_i_e 的预测误差
```

它的作用是让稳定分支保留长期有用的预测信息。

### 3. 残差目标对齐损失

该损失把 `delta_e` 与真实 Stage III 任务连接起来：

```text
residual(t) = y(t) - y_base(t)
residual_change(t) = residual(t) - residual(t-1)
```

如果 `delta_e` 与残差或残差变化没有关系，那么它即使几何上很漂亮，也不能支持在线修正。

### 4. 正交或泄漏控制损失

该损失减少稳定表示和残差表示之间的信息重复。

可用诊断包括：

- `phi_i_e` 与 `delta_e` 的余弦平行比例；
- 用 `phi_i_e` 预测 `delta_e` 的岭回归解释度；
- 稳定分支与残差分支的相关矩阵；
- 残差转移信号的有效秩；
- 残差分支是否塌缩到接近零。

### 5. 专家使用率和多样性约束

该约束防止所有样本集中到少数专家。

可用诊断包括：

- 专家权重熵；
- 有效专家数量；
- 最小专家使用率；
- 每个专家的残差目标可预测性；
- 每个专家的环境分布差异。

### 6. 环境推断因果约束

环境推断必须明确训练期和部署期的可见信息边界。

如果训练期环境标签依赖真实 `y`，那么部署期不能直接使用这套环境标签作为在线输入。可以考虑训练期学习环境原型，部署期用冻结的因果分类器近似匹配。

## 十二、V16 必须通过的诊断矩阵

### Stage 0：形状和恒等测试

必须证明：

- 张量形状稳定；
- `phi_v_e = phi_i_e + delta_e`；
- 零 `delta_e` 产生零漂移贡献；
- 训练集拟合的归一化器不会在验证集或测试集重新拟合；
- VAE 评估阶段保持确定性或被严格控制。

### Stage 1：表示诊断

必须记录：

- 每个专家的 `delta_e` 范数；
- `delta_e(t) - delta_e(t-1)` 的转移范数；
- 残差信号有效秩；
- 表示塌缩比例；
- `phi_i_e` 到 `delta_e` 的泄漏解释度；
- 专家使用率熵；
- 环境后验熵；
- 每个专家的样本覆盖量。

这些诊断只能说明表示是否健康，不能单独证明方法有效。

### Stage 2：teacher-only 可预测性门槛

必须比较：

```text
history_only
expert_delta_only
expert_delta_plus_history
global_delta_plus_history
level_offset_plus_history
```

最关键的判断是：

```text
expert_delta_plus_history 是否稳定优于 history_only。
```

这一步直接继承 V15 的核心经验。

### Stage 3：反事实归因门槛

真实专家漂移信号必须优于反事实信号。

反事实信号至少包括：

- 零信号；
- 随机打乱信号；
- 符号翻转信号；
- 放大信号；
- 随机同范数信号；
- 固定历史条件下的条件打乱信号。

如果真实信号和反事实信号效果接近，就不能说模型利用了有意义的专家局部漂移。

### Stage 4：公共数据集矩阵

只有 Panama seed 42 的 canary 通过之后，才建议扩展到：

```text
datasets: panama, tetouan, spain_energy_weather
seeds: 42, 43, 44
rolling windows: 5
```

这一阶段仍然应该先做 teacher-only，不应该直接训练生成器。

### Stage 5：生成器 canary

只有 teacher-only V16 门槛通过后，才允许训练生成器。

如果 teacher-only 路径不能稳定修正残差，那么生成器训练没有科学依据。

## 十三、当前可以写和不能写的论文表述

当前可以写成设计假设：

```text
我们提出一个专家局部双流不变残差表示假设，旨在降低稳定表示与可变残差信号之间的坐标错配风险。
```

当前可以写成算法更正方向：

```text
该设计在每个专家分支内部共享大部分表示层，并在后段显式分离稳定表示和可变残差，从而使漂移信号构造从事后相减转为结构化残差建模。
```

当前不能写成：

- Stage III 已经学到了概念漂移；
- 专家局部不变学习已经提升了在线预测；
- `phi_v - phi_i` 的问题已经被完全解决；
- 正交约束证明了不变因素和可变因素因果解耦；
- 新设计已经超越 SOTA；
- 当前证据已经支持训练 Stage III generator；
- 环境推断模块已经可以部署。

## 十四、建议的论文安全表述

如果在论文中讨论这个方向，建议使用如下谨慎表述：

```text
Motivated by the negative Stage III audits, we consider an expert-local dual-stream redesign in which stable and residual variation signals are derived from a shared late representation within each expert. The redesign aims to reduce coordinate mismatch in drift-signal construction. However, the mechanism remains a hypothesis until expert-local residual signals show incremental predictive value beyond causal residual-history controls.
```

中文含义是：

```text
受 Stage III 负向审计结果启发，我们考虑一种专家局部双流重构方案。该方案在每个专家内部从共享后段表示中同时导出稳定表示和可变残差信号，以降低漂移信号构造中的坐标错配风险。但是，在专家局部残差信号证明自己能稳定超越因果残差历史之前，该机制只能被视为待验证假设。
```

不要使用如下表述：

```text
The proposed module solves concept drift.
```

更安全的替代表述是：

```text
The proposed redesign makes drift-signal construction more auditable by deriving stable and residual signals from shared expert-local representations.
```

中文含义是：

```text
该重构方案通过从专家局部共享表示中导出稳定信号和残差信号，使漂移信号构造过程更容易审计。
```

## 十五、新思路风险登记表

| 风险 | 严重性 | 说明 | 必要控制 |
| --- | --- | --- | --- |
| 新信号仍然不能超过 `history_only` | Critical | V15 已经表明这是当前最核心失败模式。 | 必须先做 V15 风格残差目标门槛。 |
| 环境推断泄漏标签 | Critical | 如果环境由当前标签或当前残差决定，就不符合在线预测设定。 | 明确因果输入契约和 delayed-label 协议。 |
| 专家塌缩 | High | softmax 门控可能长期只使用少数专家。 | 记录专家熵、有效专家数和最小使用率。 |
| 正交约束删除有用信号 | High | 投影可能把残差中真正有用的部分也删掉。 | 做有无正交约束的残差可预测性消融。 |
| 参数量增加导致过拟合 | High | 每个专家增加双流头会提高小样本风险。 | 先做 teacher-only canary 和 rolling validation。 |
| 几何更漂亮但没有预测价值 | Critical | V12 已经显示对齐改善不等于 teacher gate 通过。 | 必须要求增量超过因果历史基线。 |
| 环境标签只是复制时间或历史残差 | Medium | 环境模块可能学到的是季节或历史残差代理。 | 加入固定历史条件下的条件打乱对照。 |
| 不同专家局部坐标再次不可比 | Medium | 如果每个专家完全独立学习，跨专家信号仍可能错配。 | 使用共享后段模板、共享锚点和专家级对齐诊断。 |

## 十六、最小安全下一步

最小安全下一步不是训练生成器，也不是重写整个 Stage III。

最小安全下一步是：

```text
撰写 V16 设计规格，并只实现 expert-local dual-stream teacher-only 诊断。
```

这份规格必须先定义：

1. 从哪个专家状态提取 `h_e(t)`；
2. 如何构造 `phi_i^e(t)`、`delta_e(t)`、`phi_v^e(t)`；
3. 环境推断在训练和部署时分别能看见什么；
4. 如何保证零漂移恒等；
5. 如何度量正交和泄漏；
6. 如何诊断专家塌缩；
7. 如何比较 `expert_delta_plus_history` 和 `history_only`；
8. 什么门槛通过后才允许生成器训练。

只有这份规格完成并经过审查后，才应该进入代码实现。

## 十七、最终结论

你的新思路在方向上是合理的。它把问题从“两个向量能不能直接相减”推进到“如何在同一个专家局部坐标系统中显式学习稳定表示和可变残差”。这个方向比旧的后处理式相减更符合数学和深度学习建模原则。

但是，它不能被当成已经解决 Stage III 的方案。当前最强证据表明，Stage III 的关键瓶颈是漂移信号没有稳定提供超出因果残差历史的增量信息。V16 必须首先证明 expert-local residual signal 在 teacher-only 设定下有效。

因此，我建议把这个方向定位为：

```text
高价值算法更正假设，而不是已验证贡献。
```

在报告、论文和后续代码中都应保持这个边界。
